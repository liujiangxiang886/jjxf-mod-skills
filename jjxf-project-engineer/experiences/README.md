# 增量经验区（experiences/）

这个目录存放**稳定核心知识之外的新经验**——新作者踩的坑、新版本带来的变化、新的工具用法。

## 命名规则

`<日期>-<简短主题>.md`，例如：
- 《2026-11-20-4.8线新基线指纹.md》
- 《2026-12-03-某作者text_patches scope坑.md》

按日期倒序排列，最新的在最前面（文件名排序即可）。

## 什么时候写这里，什么时候改 references/

| 情况 | 写到哪里 |
|---|---|
| 一条新的、局部的经验/坑/问答 | 这里，新建一条 |
| 新版本带来的重大变化（如新引擎线） | 这里新建，并在 LEARNING.md 登记待合并 |
| 新经验**推翻**了旧结论 | 这里新建，`supersedes` 字段填被推翻的出处；走 LEARNING.md 的"知识升级"流程 |
| 只是补充细节、让表述更准 | 直接微调对应 references 文件 |

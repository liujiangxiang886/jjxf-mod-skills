## 一、MOD 到底是什么（给新手的第一课）

MOD（Modification）= 在不改游戏原始程序的前提下，新增或改变游戏内容。三种常见形态：

| 形态 | 做法 | 典型例子 |
|---|---|---|
| **数据/资源替换** | 换贴图、音频、配置表、剧情文本 | 汉化包、换皮、数值调整 |
| **内容追加** | 加新武器、新角色、新关卡、新剧情 | 角色武器 MOD、剧情扩展包 |
| **脚本逻辑改动** | 注入/覆盖脚本，改行为 | 战斗机制调整、新增系统 |

关键原则：**能不能做某种 MOD，取决于目标游戏开放了什么**（有无 MOD 工具、源码、扩展接口）。
通用 Godot 工程里你能改节点写脚本；但编译发行的商业游戏通常只开放资源层——这就是分层判定的由来。

## 二、做一个"新角色武器"需要什么（通用 Godot 工程）

一个可用的武器通常由四部分组成。给新手按这个清单问，缺哪个补哪个：

| 组成 | 作用 | Godot 里的实现（4.x） |
|---|---|---|
| **数据定义** | 伤害、攻速、射程、稀有度、图标、名称 | `Resource` 自定义类（`.tres`），或 `Dictionary`/JSON 配置表——数据驱动，改数值不用动代码 |
| **视觉表现** | 武器外观、持握位置、动画 | 场景（`.tscn`）：`Sprite2D`/`AnimatedSprite2D`/`MeshInstance3D`（2D 还是 3D 先定），挂到角色的 `Marker2D`/`Bone2D`（挂点） |
| **行为逻辑** | 攻击判定、弹道、命中效果 | 脚本（`.gd`）：`Area2D` + `CollisionShape2D` 做攻击范围，触发 `body_entered`/`area_entered`；或射线 `RayCast2D` |
| **接入方式** | 让游戏知道这把武器存在 | 注册到武器表（Resource 数组 / 目录扫描 / 数据 id），再在角色装备逻辑里实例化武器场景并传数据 |

新手最容易漏的两点：
1. **挂点与坐标**：武器要跟着角色动画走，必须先定好挂点（Marker/Bone），否则手持位置会飘。
2. **数据与表现分离**：数值写死在脚本里，后面调平衡会很难受——用 Resource 存数据是通用最佳实践。

> ⚠️ 以上是"自己有源码的 Godot 工程"的做法。**机甲旋风项目不能这样做**：本体不能改源码重编译，
> 4.7 只有 `.gdc` 字节码。在那边做武器相关 MOD 靠的是数据覆盖 + 插桩，具体看 `02-mod-toolchain.md`。

## 三、动画帧怎么搭配（Godot 4.x 三套机制）

新手常把三套动画机制混为一谈。先讲清"什么时候用哪套"，再讲搭配：

| 机制 | 适合 | 核心节点/资源 | 典型用法 |
|---|---|---|---|
| **逐帧精灵动画** | 2D 序列帧（角色走动、攻击、特效） | `AnimatedSprite2D` + `SpriteFrames` | 把每帧图排进 SpriteFrames，设 FPS、循环，代码里 `play("attack")` |
| **关键帧动画** | 动任意属性（位置/旋转/缩放/颜色/可见性），或 3D | `AnimationPlayer` + `Animation` | 建动画轨道，插入关键帧，设时长/缓动，`play("swing")` |
| **动画状态机** | 多状态混合、过渡（待机↔跑↔攻击） | `AnimationTree` + `AnimationNodeStateMachine` | 把 AnimationPlayer 的动画连成状态图，设过渡条件，`set("parameters/...")` |

**搭配原则**：
- 2D 角色：常见是 `AnimatedSprite2D`（管逐帧外观）+ `AnimationPlayer`（管位移/命中框/特效触发）配合。
- 3D 角色：主要用 `AnimationPlayer` / `AnimationTree`。
- 状态多、要平滑过渡：上 `AnimationTree`，别在代码里手写一堆 `if` 切动画。

**序列帧实务要点**（真会踩的坑）：
- 帧尺寸统一、锚点（pivot）一致，否则播放时抖动；
- FPS 决定快慢，`SpriteFrames` 里每帧可单独设时长；
- 攻击动画的"有效帧"要和判定框开启时机对齐——这是打击感的关键，通常用 `AnimationPlayer` 的 `call()` 方法轨道在指定帧触发判定；
- 循环动画（待机/走动）与一次性动画（攻击/受击）分开设置，别让攻击循环。

> ⚠️ 同样注意分层：以上是通用 Godot 工程。"动画帧"落到机甲旋风 4.7 剧情扩展包时，
> 涉及的是剧情层 pck 替换与锚点重算（见 `01-engine-lines.md` §剧情层替换、`08-version-maintainer.md` §换剧情层），
> 不是简单换个 SpriteFrames。

## 四、4.7 剧情扩展包怎么接入（项目层指路）

这是**项目层问题**，通用层不臆测。给新手的正确引导路径：

1. 先读 `01-engine-lines.md` §剧情层替换——剧情层是 4.7 的"第一原文"，排在 mod 之前，
   层级是 `baseline → story → mod overlay × N → sources 兜底 → merged → instrumented`。
2. 接入步骤、锚点重算、通知作者的规范在 `08-version-maintainer.md` §3.1 换剧情层。
3. 换层后旧扩展会因锚点失配失效——这是**必然**，不是可能；先停用扩展再换层。
4. 具体参数、路径、错误码一律从项目层 references 取证，不给通用 Godot 答案。

## 五、给新手的回答范式

新手往往说不清自己要什么。用这四个问题快速定位，再给方案：

1. **目标游戏是谁**？有自己的 Godot 工程源码（通用层）还是编译发行的成品（项目层）？
2. **改什么**：资源替换 / 内容追加 / 逻辑改动？
3. **2D 还是 3D**？——决定动画与碰撞用哪套节点。
4. **有没有现成工具/扩展接口**？——决定能做到哪一层。

问清后再按"结论 → 清单/步骤 → 出处或边界说明"回答。**不确定目标平台时先问，不默认套用通用做法。**
